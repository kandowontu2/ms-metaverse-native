# Contributing

Bug reports and clean-room parity improvements are welcome. Please include the
exact scene, contestant, action sequence, expected original behavior, and the
native behavior. Screenshots or short recordings help, but do not upload
copyrighted disc images or extracted game media.

Before submitting code, run:

```powershell
./scripts/release-audit.ps1
```

Contributions must not add original game assets, installer binaries, disc
images, decompiled original source, secrets, or code copied from a proprietary
source. Behavioral observations, independently written code, metadata, and
reproducible extraction tools are in scope.
